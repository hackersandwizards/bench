# T53, T54, T59 (ai-tells.md:27-37, 62-71): rhythm patterns that survive paraphrase
FAIL if the post carries any of these three:
1. A forced triplet: three parallel adjectives, nouns or clauses set up for rhythm ("faster, calmer, and more confident"; "They wrote X. They built Y. They argued about Z."). Three concrete items in one clause with varied length ("a CLAUDE.md, a review agent and a migration agent") are not one.
2. Two or more one-line aphorisms in a row ("Slow is smooth. Smooth is fast."). A sentence that states a fact of the story is not an aphorism.
3. A paragraph that runs framing claim, expansion, contrast pivot ("but", "however", "not X, it's Y"), takeaway, end to end.
Otherwise PASS.
