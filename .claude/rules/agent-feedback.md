# Agent Feedback

After a user corrects, refines, or externally edits work you produced, complete the requested
result first, then load `agent-feedback` and improve whatever owns the behaviour before finishing
the turn. That skill owns the counterfactual, the choice of owner, and the action boundary.

Load it before writing or editing a skill, agent definition or rule too: it states what such an
artifact leaves out, the history behind a rule included.
